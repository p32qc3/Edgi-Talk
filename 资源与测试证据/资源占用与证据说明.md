# Edgi-Talk 资源占用与证据说明

本文件记录与参赛报告一致的模型、双核通信和固件资源口径。数据来自当前 stable 构建的源码、`rt-thread.elf`、链接 map 与 `metrics.json`。

## 1. 模型部署规模

- 输入：16 kHz、16 位单声道；1 s 窗口；49×40 log-mel。
- 网络：Conv2D(8, 5×5) → MaxPool(4×4) → Conv2D(16, 3×3) → GAP → Dense(32) → Dense(5)。
- 参数量：2,085。
- float32 权重：8,340 B（约 8.14 KiB）。
- 模型权重、mel 滤波器组与 Hann 窗常量合计约 50.18 KiB。
- 当前源码中 AI 链路已知静态缓冲与 AI 线程栈预算约 126.6 KiB；该值不是整核动态峰值。

## 2. 双核共享通信

- 固定共享地址：`0x261C0000`。
- 共享结构总长：64 B，并由编译期静态断言校验。
- 前 32 B：M33 写入告警结果、服务状态与 seq。
- 后 32 B：M55 写入命令、完成序号、WiFi/UI/上传状态与心跳。
- M33 发布：写数据 → 内存屏障 → seq 递增 → flush 前 32 B。
- M55 读取：invalidate 前 32 B → 读 seq1 → 复制字段 → 读 seq2；仅接受相同且非零的 seq。
- M55 下发命令与 M33 回执同样采用序号、屏障和后 32 B 定向 cache 维护。

## 3. 固件链接后资源

| 核心/区域 | 区域容量 | 使用或链接分配 | 口径 |
|---|---:|---:|---|
| M33 NVM | 2,097,152 B | 172,968 B | 8.25%，text+data |
| M33 片内数据区（不含 heap） | 262,144 B | 162,989 B | 62.2%，静态段 |
| M33 预留 heap | — | 95,048 B | 链接预留 |
| M55 NVM | 8,388,608 B | 965,916 B | 11.5%，text+data |
| M55 片内代码区 | 262,144 B | 72,640 B | 27.7%，ITCM 与向量 |
| M55 片内数据区 | 262,144 B | 180,796 B | 69.0%，data+bss+noinit |
| M55 图形缓冲区 | 3,145,728 B | 2,654,208 B | 84.4%，双缓冲及 graphics_buffer |
| M55 扩展数据 heap | 1,441,792 B | 1,441,768 B | 链接预留 |

“链接预留”只用于说明固件能否装入目标分区，不代表运行时最高水位。动态内存峰值需要在真机连续运行时采集 RT-Thread 内存统计后才能给出。

## 4. 已有测试结果

- 离线验证：657/848，准确率 77.5%。
- 离线环境门控：707/730 保持背景，通过率 96.8%。
- 板载回采复核：四类各 5 个窗口，门控后 20/20。
- 现场测试：火警 10/20、敲门 16/20、烧水 18/20、婴儿啼哭 12/20；合计 56/80，正确率 70.0%。

动态内存最高水位、端到端时延和连续运行时长没有实测记录，因此未写成性能结论。
