# LSM6DS3TR-C register driver

Unmodified ST register driver copied from the installed Edgi-Talk BSP 1.2.1:
`projects/Edgi_Talk_M33_LSM6DS3/packages/lsm6ds3tr`.
The example platform file is deliberately not compiled: this application uses
bounded initialization and one dedicated sampling thread in `pet_imu.c`.

Upstream: https://github.com/STMicroelectronics/lsm6ds3tr-c-pid
Copyright and license notices in the source files are retained.
