# A+B 整合版构建与烧录说明

## 工程分工

- M33：负责底层启动，并在 M55 保存宠物数据时协调外部存储访问。
- `M55_Edgi_Pet_A1`：运行宠物界面、游戏、51 通信和离线 AI 指令。
- 原 `M55_Edgi_Talk_LVGL` 保留，不在整合过程中覆盖。

## 烧录顺序

1. 编译并烧录 M33 工程。
2. 编译并烧录 `M55_Edgi_Pet_A1`。
3. 复位开发板，确认屏幕右上角显示 `AI:DEMO | 51:WAIT | AB1`。
4. 接上 51 后，状态应自动变为 `51:LINK`；拔线后应回到 `51:WAIT`。

不要交换前两步的顺序。重新烧录任意一侧后，建议将两侧都按上述顺序重烧一次。

## 51 串口接线

通信采用 TTL UART，115200 波特率，共三根线：

| Edgi-Talk | 51 单片机 |
| --- | --- |
| UART5 TX（软件配置为 P17.1） | P3.0 / RXD |
| UART5 RX（软件配置为 P17.0） | P3.1 / TXD |
| GND | GND |

TX 与 RX 必须交叉，且两块板必须共地。P17.0/P17.1 对应的实体排针位置请以手中板卡丝印和官方原理图为准。

## 当前离线 AI 指令

- `开始游戏`、`记忆灯`、`simon`：启动记忆灯游戏。
- `查看状态`、`状态`、`status`：打开宠物状态页。
- 其他文本不会直接执行操作，避免异常输出误控制设备。

在 M55 控制台可使用 `ai_demo simon` 或 `ai_demo status` 做演示检查。网络大模型和语音识别不属于当前离线稳定版。

## 验收结果

未连接 51 时，宠物界面、触摸、姿态、游戏和数据保存应可独立工作，状态显示为 `51:WAIT`。连接 51 后，游戏指令只应被确认一次，游戏结果能回到宠物系统；连接中断后系统不应卡死，并能在恢复接线后自动重连。
