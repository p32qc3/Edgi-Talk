# Edgi-Talk 重要代码说明

本压缩包用于竞赛网站“重要代码”上传，保留作品自行实现和重点修改的部分，不包含体积较大的完整 SDK、第三方软件包和编译缓存。

## 目录

- `M33_Edgi-Talk_Audio`：板载采音、log-mel 特征、轻量卷积网络、结果门控、共享内存发布及模型训练工具。
- `M55_Edgi_Talk_LVGL`：共享内存稳定读取、LVGL 中文界面、WiFi 配网、HTTP 告警上传及云端钉钉转发服务。
- `模型与验证`：当前部署模型及对应离线验证结果。
- `现场工具`：电脑端 WiFi 配网工具。

## 结果口径

- `metrics.json` 对应当前部署权重，共 848 个独立离线验证窗口，正确 657 个，总体准确率 77.5%。
- 报告中的 20/20 为板载麦克风回采的小样本离线复核，不代表完整现场泛化性能。
- 现场四类告警各测试 20 次：火警 10/20、敲门 16/20、烧水 18/20、婴儿啼哭 12/20，合计 56/80，总体正确率 70.0%。
- 未实测的数据不作推断：动态内存最高水位、端到端时延、连续运行时长等仍需在真机上另行采集。

## 模型、双核与资源证据

- 当前五分类网络共 2,085 个参数，float32 权重 8,340 B（约 8.14 KiB）；训练脚本、板端权重数组和 `metrics.json` 相互对应。
- 双核共享结构固定在 `0x261C0000`，总长 64 B；M33 与 M55 各写 32 B，结合内存屏障、cache 分区维护和 seq 双读保证稳定快照。
- 当前 stable ELF/map 的静态结果：M33 `text+data` 为 172,968 B；M55 `text+data` 为 965,916 B。详细口径见 `资源与测试证据/资源占用与证据说明.md`。

## 编译说明

该压缩包不是独立 SDK。完整编译需要在 RT-Thread Studio 中导入工作区内的两套完整工程，并使用其已有板级支持包、链接配置和工具链。现场演示所用完整工程与可烧录文件保留在比赛电脑工作区中。

## 安全说明

公开仓库不包含真实 ECS 地址、钉钉 Webhook、WiFi 密码或私有密钥。示例中的 `YOUR_ECS_IP_OR_DOMAIN`、`CHANGE_ME` 与 `YOUR_TOKEN` 仅用于说明配置位置，部署时必须替换。
